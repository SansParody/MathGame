# MathGame
<p>Обучающая игра, нацеленная на обучение и закрепление навыков по высшей математике.</p>

# Основные возможности
- Прохождение математических заданий.
- Проверка ответов и отображение обратной связи.
- Выбор уровня сложности.
- Отображение итогов прохождения.

# Установка
<p>Скачать <a href="https://github.com/SansParody/MathGame/releases">архив</a> и распаковать.</p>

# Использование
Запустить .exe файл.
